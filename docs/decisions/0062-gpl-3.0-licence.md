# 0062. License Comilito under the GPL-3.0

- Status: Accepted
- Date: 2026-11-20

## Context

Comilito had no licence file. `Cargo.toml`, `package.json` and the Flatpak metainfo said `MIT`,
the most permissive common licence, which allows anyone to take the code into a closed product
and sell it. The author wants Comilito open source, and doesn't want others profiting from it
commercially.

A licence that forbids commercial use isn't open source: the Open Source Definition (and the
Free Software Foundation's) requires that anyone may use the code for any purpose, selling
included. Flathub lists apps under such licences as proprietary.

## Options considered

- **MIT (as declared):** open source, but allows closed commercial reuse.
- **PolyForm Noncommercial 1.0.0:** forbids commercial use by others (the copyright holder is
  never bound by their own licence), but it's source-available, not open source; Flathub would
  show Comilito as proprietary. Creative Commons NC licences are made for art and text, not code.
- **GPL-3.0:** open source and free software. Commercial use is allowed, but anyone distributing
  Comilito or a program made from it must do so under the GPL, with its source, so it can't
  become part of a closed product. The author can still sell other licences (dual licensing),
  for code they hold the rights to.
- **AGPL-3.0:** the GPL plus the same duty for software offered over a network. Comilito is a
  desktop app, so it would add nothing.

## Decision

Comilito is licensed under the **GPL-3.0-only** (SPDX identifier). `LICENSE` holds the full text;
`Cargo.toml`, `package.json` (and its lock file) and the metainfo's `project_license` name it,
and the README and the website say so.

"Only" rather than "or later": later versions of the GPL, whose terms aren't known yet, don't
apply unless the author chooses to relicense.

Every dependency's licence is compatible: MIT, Apache-2.0, BSD, ISC, zlib, MPL-2.0, Unicode and
other permissive licences (checked with `cargo metadata` and package-lock.json). The sample audio
(CC BY) and fonts (OFL) are separate works under their own licences, listed in CREDITS.md. yt-dlp
and ffmpeg are separate programs downloaded at run time, not linked (decision 0019).

## Consequences

- Comilito is open source and free software; Flathub lists it as such.
- Others may use it, even commercially, but can't distribute it, or anything built from it, as
  closed source.
- Contributions come in under the GPL too. Selling Comilito under other terms (dual licensing)
  would need the rights to every contribution, usually through a contributor agreement; there's
  none yet.
- New dependencies must be GPL-3.0-compatible (no "non-commercial", proprietary or GPL-2.0-only
  code).
- Much of the code was written with AI. How far copyright, and so the licence, covers purely
  AI-generated code is unsettled law; the author's design, selection and changes are what's most
  clearly protected.
